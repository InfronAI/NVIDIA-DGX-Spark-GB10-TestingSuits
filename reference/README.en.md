# Historical algorithm reference

These files preserve original serving, statistical, cache, length, hardware, engine and completion algorithms. A`.txt` suffix separates them from current executable entry points. Hosts, credentials and personal paths are sanitized; hashes differ from private originals. See `../provenance/import-manifest.json`.

Use the root `sparkbench` CLI for current execution. Original full-report builders depend on private billing/archive layouts and are references only. `sparkbench summarize` reconstructs key summaries from published data. Full reports are frozen bilingual deliverables.

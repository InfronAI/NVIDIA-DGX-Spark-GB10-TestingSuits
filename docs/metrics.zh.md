# 指标字典

| 指标 | 定义／单位 | 解读边界 |
| --- | --- | --- |
| 正文首字等待 | 客户端发送到首个非空正文片段，秒 | 不包括仅思考片段；不是GPU预填充时间 |
| 首生成片段等待 | 首个正文／思考／工具生成事件，秒 | 一个事件可包含多个词元 |
| 端到端延迟 | 发送到流结束，秒 | 包括排队、网络、引擎与终态传输 |
| 平均后续词元耗时 | (结束−首生成事件)/(生成数−1)，秒/词元 | 近似均值，不是逐词元间隔分布 |
| 聚合吞吐 | 同组生成词元合计/连续区组墙钟合计，token/s | 不能平均单请求速率来替代 |
| Goodput | 满足声明的首字/端到端目标的请求或词元/秒 | 目标阈值、到达分母和失败必须可见 |
| 到达／接纳／完整率 | 到达数、发送数、完整响应数，各自分母明确 | 本地拒绝也占到达分母 |
| 引擎阶段 | 队列、预填充、解码的进程内持续时间 | 不跨进程绝对时钟做差 |
| GPU阶段活跃 | 同节点相应GPU事件区间并集 | 不叠加嵌套事件或两个rank |
| MTP接受情况 | 引擎原生接受长度、验证数、接受率 | 配置开启与运行接受率分别记录 |
| 缓存词元比例 | 缓存词元/输入词元；计数器则同窗差值比 | 共享输入比例和缓存命中率不同；重置窗口无效 |
| 矩阵算力 | 2MNK×调用数/CUDA区间/10¹²，TFLOP/s | FMA计2操作；稠密与稀疏工作量分别定义 |
| 逻辑内存带宽 | 声明的读写字节/设备区间/10⁹，GB/s | copy读＋写为2N；不同于物理DRAM字节 |
| 依赖访问 | 串行依赖链时间/访问次数，ns | 不是所有线程混合吞吐 |
| 集合通信算法带宽 | 消息语义字节/较慢rank同轮耗时 | AllGather的消息字节按完整输出定义 |
| 集合通信bus带宽 | 算法带宽×操作与rank数对应系数 | 不是网卡线速，也不自动证明RDMA |
| 计算通信重叠 | 同轮serial/overlap；另报隐藏比例 | 工作量相同，模式配对；不混入TCP控制时间 |
| 功率／能量 | 传感器W、有效邻接区间积分J | GPU/SoC传感器不是插座整机能耗 |
| 温度／时钟／利用率 | °C、MHz、%及采样覆盖 | 热阈值是实验主动控制，不自动等于驱动降频 |
| 实付成本／ROI | 已核对费用；1/3/5年情景现金流 | 未核对费用不填0；折旧不能重复从现金流扣除 |

数据表的缺失值为空或null，不用0冒充。每个图表需给出条件、样本数和计时边界。

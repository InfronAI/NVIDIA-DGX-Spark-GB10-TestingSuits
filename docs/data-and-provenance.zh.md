# 代码、数据与来源

| 内容 | 发布位置 | 含义 |
| --- | --- | --- |
| 当前可执行代码 | `src/sparkbench`、`benchmarks/gb10` | 参数化适配；默认只预览，需要显式execute |
| 原实验算法 | `reference/2026-study` | 经清理的参考源码，以`.py.txt`等形式保存；不是可直接部署的产品 |
| 请求与测量表 | 各实验`data/` | 保留失败与条件边界，可复算关键结论 |
| 方案／材料身份 | 各实验`protocols/` | 冻结设计、题目索引、版本和散列 |
| 完整报告 | 各实验`reports/` | 中英文Markdown、HTML、PDF；图形单独可引用 |
| 导入凭据 | `provenance/import-manifest.json` | 原文件与发布文件散列及变换记录 |

凭证、个人磁盘路径和实际节点域名已清理；示例地址不代表可访问服务。生产停服／部署控制器、账户账单原文、完整HTTP载荷、模型权重、大型trace和50,000余项本机文件目录不进入仓库。参考代码和分析表覆盖本次公开结论的主要算法与数据，但不是逐字节完整私有归档。完整报告中的历史文件索引只描述原研究归档，不意味着所有附件随GitHub仓库分发。

本地原始档案保留，不由发布脚本改写。报告的失败、缺口与不确定性均保留。`artifacts.json`检验发布后完整性；导入manifest记录原始hash，而运行模块后续可有明确的移植变更。代码许可不覆盖模型／数据集第三方条款。

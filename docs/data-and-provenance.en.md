# Code, data and provenance

| Material | Location | Meaning |
| --- | --- | --- |
| Current executable code | `src/sparkbench`, `benchmarks/gb10` | Parameterized adapters; dry-run by default, explicit execute |
| Historical algorithms | `reference/2026-study` | Curated source as `.py.txt` etc.; not a deployable controller |
| Request/measurement tables | Per-experiment `data/` | Preserve failures and conditions; reconstruct key findings |
| Protocol/material identity | Per-experiment `protocols/` | Frozen design, prompt indexes, versions and hashes |
| Full reports | Per-experiment `reports/` | Chinese/English Markdown,HTML,PDF and individual figures |
| Import receipts | `provenance/import-manifest.json` | Original and published hashes plus transformations |

Credentials, personal paths and real node domains are removed. Example addresses are not live services. Production stop/deployment controllers, raw account billing, full HTTP payloads, weights, large traces and the 50,000+ item local inventory are not distributed. Reference algorithms and analytical tables support the principal published conclusions; this is not a byte-for-byte private archive. Historical file indexes in the report describe the original study, not attachments guaranteed to exist in GitHub.

Original local archives remain unchanged. Failures, gaps and uncertainty are preserved. `artifacts.json` verifies distributed artifacts. The import manifest records original hashes; executable adapters may have explicitly documented portability changes afterward. Software licensing does not override model/dataset terms.
